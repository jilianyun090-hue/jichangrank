## 🚀如何下载、配置和导入该机场节点订阅？

有了机场提供的节点订阅链接（子弹），我们接下来就需要在您的设备上安装专门的代理软件（枪），并将子弹装入枪膛。请根据您的设备类型，选择对应的教程：

### 1. Windows 电脑端配置（推荐使用 Clash Verge Rev）是什么？又该如何选择和使用？
在 2026 年，原版的 Clash 已经停更，功能更强大且支持中文的 **Clash Verge Rev** 成为了 Windows 系统的绝对首选。
1.  **下载软件**：在机场后台的“软件下载”专区，下载 Windows 版本的 Clash Verge 压缩包或安装包，并完成安装。
2.  **打开软件**：双击运行。如果界面是英文，可以在左侧菜单栏点击 `Settings`（设置），找到 `Language`（语言）将其改为 `简体中文`。
3.  **导入订阅**：点击左侧的 **“配置 (Profiles)”**。在上方长条输入框中，粘贴您之前复制好的**机场订阅链接**，然后点击右侧的 **“导入 (Import)”** 按钮。
4.  **激活配置**：列表里会出现一个新下载好的配置框。右键点击它，选择 **“使用 (Use)”**（边框变色即代表激活）。
5.  **开启代理**：点击左侧的 **“代理 (Proxies)”**，挑选一个延迟较低的节点（如香港或日本）。最后回到 **“设置 (Settings)”**，打开 **“系统代理 (System Proxy)”** 的开关。
🎉 恭喜！您现在可以打开浏览器，尝试访问 Google 了！

### 2. Mac (苹果电脑) 平台配置（推荐使用 ClashX Pro）是什么？又该如何选择和使用？
Mac 用户的首选依然是轻量且优雅的 **ClashX Pro**。
1.  **下载软件**：从机场后台下载 ClashX Pro 的 dmg 安装文件，拖拽到应用程序文件夹中。
2.  **赋予权限**：首次打开可能会提示需要安装小帮手程序，请输入您的 Mac 开机密码允许安装。
3.  **导入配置**：在屏幕顶部的状态栏中，找到一个小猫咪（或类似盾牌）的图标，点击它。
4.  依次选择：**“配置 (Config)”** -> **“托管配置 (Remote Config)”** -> **“管理 (Manage)”**。
5.  在弹出的窗口中点击 **“添加 (Add)”**。在 URL 一栏中粘贴您的订阅链接，点击确定。
6.  **开启代理**：再次点击顶部状态栏的小猫咪图标，确保勾选了 **“设置为系统代理 (Set as System Proxy)”**。在“节点选择”里挑一个你喜欢的国家，开始冲浪！

### 3. Android (安卓手机) 平台配置（推荐使用 FlClash）是什么？又该如何选择和使用？
安卓平台的生态极其开放，这里推荐界面最美观、对新手最友好的 **FlClash** 或经典的 **v2rayNG**。
1.  **下载 App**：因为在应用商店搜不到，您必须在手机浏览器里登录您的机场官网，在下载专区直接下载 `.apk` 安装包并安装。
2.  **导入订阅**：打开 App，点击底部的 **“配置 (Profiles)”**。点击右上角的 **“+”** 号，选择 **“从 URL 导入”**，粘贴您的订阅链接，给它随便起个名字，点击保存/确定。
3.  **启动翻墙**：回到 App 的首页（仪表盘），你会看到一个巨大的 **“启动”按钮**。点击它！首次启动时，系统会弹出一个安全警告提示“创建 VPN 连接”，不用担心，点击**“始终允许”**。
此时，手机顶部状态栏会出现一个 `VPN` 或小钥匙图标，代表翻墙成功！

### 4. iOS (苹果手机/iPad) 平台配置（必须使用 Shadowrocket 小火箭）是什么？又该如何选择和使用？
由于苹果极其封闭的生态，国内的 App Store 是绝对下载不到任何翻墙软件的。您必须使用被誉为神器的 **Shadowrocket（小火箭）**。
1.  **准备非国区 Apple ID**：由于小火箭需要花费 2.99 美元购买，您需要准备一个美国区（美区）的 Apple ID。部分良心机场会在官网后台免费提供已经购买过该软件的共享美区账号供大家借用下载。
2.  **切换账号下载**：打开手机的 App Store，退出您自己的国内账号，登录美区账号。搜索 `Shadowrocket` 并下载安装。（注意图标是蓝底白火箭，不要下错山寨版）。下载完后**务必切回自己的国内账号**。
3.  **导入订阅**：打开小火箭。点击右上角的 **“+”** 号。将第一行的“类型”改为 **“Subscribe (订阅)”**。在 URL 栏中粘贴您的订阅链接，点击右上角保存。
4.  **启动代理**：小火箭主界面会多出一大堆节点。随便选择一个你想连的节点（前面会打个黄色的勾），然后打开界面最上方的 **“未连接”** 开关。在弹出的系统提示中点击允许并输入锁屏密码。
当屏幕右上角出现 `VPN` 小图标时，整个世界已为您敞开。

## 💡科学上网的进阶小常识：深度解析与常见问答？

如果您已经成功配置好了上述软件，那么恭喜您成功晋级。最后，送给您三条能大幅提升上网体验的小贴士：

1.  **关于“规则/规则模式（Rule）”与“全局模式（Global）”**：
    您在软件里通常会看到这两种模式。**日常请务必保持在“规则（Rule）”模式**。在该模式下，当您访问淘宝、微信等国内软件时，它会走国内的直连网络（不费机场流量）；只有当您访问海外网站时，才会自动切换到海外节点代理。这叫“智能分流”。而全局模式会让所有流量都绕道国外，不仅网速极慢，还会导致某些国内应用无法登录。
2.  **延迟（Ping）高不代表网速慢**：
    很多新手喜欢狂点“测试延迟”，觉得哪个绿色的数字最小就选哪个。其实 Ping 值只代表建立连接的时间（对打游戏影响大）。有时候一个 150ms 延迟的美国节点，看 YouTube 4K 视频可能会比 30ms 延迟的香港节点还要流畅得多。
3.  **定期更新订阅（Update）**：
    如果有一天您突然发现所有的节点都连不上了（全部 Timeout），先别急着骂机场跑路了。进入您的软件配置页面，找到您的订阅，点击一下 **“更新 (Update)”**。这是因为机场为了对抗封锁，经常会更换服务器的 IP。
