### 1. 路由器科学上网的技术原理：旁路由与主路由

在 OpenWrt 的部署中，我们通常采用以下两种网络拓扑结构：

*   **主路由模式**：OpenWrt 路由器直接作为光猫拨号后的核心路由器，负责全屋 IP 的分配与所有数据的处理。
*   **旁路由（网关路由）模式**：全屋已有主路由器，OpenWrt 路由器仅作为网关接入内网。需要科学上网的设备，只需手动将其网络设置中的 **网关 (Gateway)** 和 **DNS** 设定为该旁路由的 IP 地址，流量便会经由其代理转发。这种方式对原有网络改动最小，最为安全稳妥。

### 2. 在 OpenWrt 中安装并配置 OpenClash 插件

**OpenClash** 是目前 OpenWrt 平台上最主流、功能最完善的 Clash 客户端插件。

#### 步骤一：安装插件
由于各个路由器的 CPU 架构（如 x86_64, Arm, Mips）不同，我们需要下载对应架构的 `.ipk` 格式插件文件，并在 OpenWrt 的 **系统** -> **软件包** (Software) 菜单中上传安装。通常还需要依赖基础组件（如 `luci-compat`、`iptables` 等）。

#### 步骤二：导入机场订阅并生成配置文件
1.  登录您的机场（例如，[极连云](https://jichang360.net/jilian.html)或[瞬云机场](https://jichang360.net/shunyun.html)），在订阅区域复制常规 Clash 订阅链接。
2.  进入 OpenWrt 网页后台，在左侧导航栏点击 **服务 (Services)** -> **OpenClash**。
3.  点击上方选项卡中的 **配置文件管理 (Config Files)**。
4.  在底部“配置文件下载”处：
    *   **订阅文件别名**：起个容易记的名字，如 `jilian-openwrt`。
    *   **订阅地址**：粘贴您刚复制的订阅 URL 链接。
5.  点击 **保存并下载** 按钮。OpenClash 会在路由器后台自动下载订阅并完成规则解析。
6.  返回 **运行状态 (Status)** 页面，选择刚才下载的配置，点击右上角巨大的 **启动 OpenClash** 按钮。

### 3. 精细化分流与性能调优设置

由于路由器的处理器（特别是普通硬路由）计算能力无法与电脑相比，不合理的设置会导致路由器高负载卡顿，甚至死机。为了提高路由器处理性能，建议在 OpenClash 设置中调整以下核心选项：

1.  **运行模式**：优先选择 **Fake-IP (TUN) 混合模式**，该模式解析 DNS 速度最快，且由于使用虚拟网卡拦截，兼容性最佳。
2.  **DNS 设置**：开启“本地 DNS 解析”和“自定义上游 DNS”，国内 DNS 填入 `119.29.29.29` 或 `223.5.5.5`；国外加密 DNS 填入 `8.8.8.8` 或 `1.0.0.1`，防止 GFW 造成的 DNS 污染。
3.  **内核升级**：在插件的“版本更新”面板中，确保已安装支持 Meta/Mihomo 的高级内核，以便解析较新的 Reality 或 Vless 节点。
