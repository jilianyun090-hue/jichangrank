### 1. 下载并安装安卓版 Sing-Box

由于 Google Play 商店在部分地区无法直接访问，建议您通过以下安全渠道获取最新的稳定版安装包：
*   **官方 GitHub Release**：前往项目官方开源地址下载最新发布的 `.apk` 文件。
*   **机场后台下载链接**：各大主流[机场推荐](https://jichang360.net/)后台通常也提供了直链下载，方便用户直接获取对应包体。

下载完成后，安装并赋予软件创建网络连接的虚拟网卡权限。

### 2. 获取并导入机场订阅配置文件

目前，大多数主流优质机场已经对 Sing-Box 进行了完美兼容。您可以直接在机场后台获取 Sing-Box 专用配置文件。

#### 步骤一：在机场后台获取链接
1.  登录您的机场（例如性价比极高的[极连云](https://jichang360.net/jilian.html)或防封锁先锋[瞬云机场](https://jichang360.net/shunyun.html)）。
2.  在仪表盘找到订阅导入区域，选择并点击 **复制 Sing-Box 订阅链接**。如果是只提供 Clash 链接的机场，您也可以使用支持在线转换的订阅转换工具将其转换为 Sing-Box 支持 of JSON 格式。

#### 步骤二：在 Sing-Box APP 中导入
1.  打开 Sing-Box 客户端，点击底部的 **Profiles** 选项卡。
2.  点击右上角的 **+ (新建)** 或 **Add Profile** 按钮。
3.  输入您的配置信息：
    *   **Name**：填写机场的名称，例如 “极连云-专线”。
    *   **Type**：选择 **Remote**（远程订阅文件，这样可以随机场动态更新节点列表）。
    *   **URL**：粘贴您刚复制 the Sing-Box 订阅链接。
    *   **Auto Update (自动更新)**：建议勾选并设置为 24 小时（1440分钟），这样每天都会在后台自动刷新机场最新的节点地址。
4.  点击右上角的 **Save** 按钮。系统会拉取该订阅配置文件，成功后返回 Profiles 列表，点击选中该配置启用。

### 3. 运行并选择节点

配置文件导入成功后，返回 APP 首页 (Dashboard) 菜单：

1.  点击页面中间 of the **Dashboard**，在策略组中，您可以自由切换网络延迟最低的节点。
2.  对于日常高负载和极速下载需求，可以手动选择[寰宇云](https://jichang360.net/huanyuyun.html)或[光年梯](https://jichang360.net/guangnian.html)提供的 IEPL 游戏/工作专线节点，不限速不卡顿。
3.  返回首页，点击右下角巨大的 **Start** 按钮开启服务。系统会自动弹出 VPN 连接请求窗口，点击“确定”或“允许”即可。

### 4. Sing-Box 安卓常见故障排查与调优

在日常使用 Sing-Box 进行外网连接时，新手用户可能会遇到一些细节问题，我们在此提供实用的排查与配置优化技巧：
*   **配置文件解析错误 (Config Parse Error)**：这通常是由于复制的 JSON 订阅链接在传输过程中被篡改，或者本地网络在拉取配置文件时发生了丢包，导致 JSON 格式不完整。解决方法是删除该 Profile 并重新复制导入，或者使用在线 JSON 工具检查配置是否闭合。
*   **路由回环与本地 DNS 污染 (Route Loop / DNS Loop)**：如果开启服务后发现手机完全上不了网（包括国内网页），请检查 DNS 设置。建议使用订阅自带的 DNS 分流规则。如果是自定义配置，请确认 Fake-IP 地址段没有与本地 Wi-Fi 路由的 DHCP 地址段发生重叠冲突。
*   **后台被安卓系统杀进程 (Background Kill)**：Sing-Box 虽然内存占用极低，但在部分国产 UI（如小米 HyperOS、华为 HarmonyOS）的严格省电策略下仍可能被后台杀掉。请务必前往手机系统设置，将 Sing-Box 设为“无限制”省电模式，并开启其“常驻后台”或加锁保护。

为了保障您的客户端在高负载下的最大稳定性，您还可以针对 Sing-Box 进行以下细节性优化：
1.  **Tun 内核配置选择**：安卓下的 Sing-Box 支持 System 和 gVisor 两种 Tun 堆栈。建议首选 **gVisor** 堆栈，其底层的用户态 TCP/IP 协议栈非常稳健，对异常包的丢弃处理极好，不容易因为偶尔的脏数据包导致整个 VPN 网卡卡死。
2.  **DNS缓存与TTL调整**：Sing-Box 默认会根据远程 DNS 解析返回的 TTL 进行本地缓存。在手机频繁切换 Wi-Fi 和基站网络（4G/5G）时，为了避免旧的 IP 缓存导致节点连接中断，建议在高级设置中将最大 DNS 缓存 TTL 设为 300 秒，以促使客户端及时更新落地节点的 IP 地址。
